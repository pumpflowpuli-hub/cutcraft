# CutCraft

**Автомонтаж видео и красивые субтитры для YouTube, Reels и Shorts.**

CutCraft сам находит паузы в речи, вырезает их, пересчитывает тайминг субтитров
под новый монтаж и вшивает текст в кадр: караоке-подсветка, всплытие слов,
свечение, скруглённые плашки и вертикальный кадр 9:16.

![Пример кадров](demo/poster.png)

---

## Что умеет

- **Умная нарезка по паузам.** Анализирует громкость с шагом 20 мс, сам подбирает
  порог под запись, оставляет запас вокруг речи и выбрасывает «э-э» и молчание.
- **Склейки по сменам сцен.** Резы по возможности попадают на смену кадра.
- **Ритм.** `--max-clip 6` режет длинные куски в самом тихом месте — для динамики.
- **Ручные резы.** `--cut 00:10-00:25` вырезает, `--keep` оставляет только нужное.
- **YouTube.** Ссылка вместо файла: скачивание через `yt-dlp`, качество до 4K,
  авто-субтитры (с пословным таймингом), главы, cookies для закрытых видео.
- **Субтитры.** SRT, VTT, ASS, YouTube `json3` или обычный текст сценария.
  Длинные реплики делятся по ширине кадра, тайминг переносится после каждого реза.
- **Красивые стили.** 7 пресетов: TikTok, караоке, неон, кино, минимализм,
  impact и подкаст. Караоке по словам, всплытие, свечение, плашки.
- **Форматы.** `9:16`, `16:9`, `1:1`, `4:5`, как в исходнике или свой `WxH`.
  Вписывание: `crop` (заполнить), `blur` (размытый фон), `pad` (чёрные поля).
- **Звук.** Музыка с автоматическим приглушением под голос (sidechain),
  нормализация громкости EBU R128, 48 кГц.
- **CLI и GUI.** Всё то же самое в тёмном окне Tkinter.
- **Превью и отчёты.** `.ass` и `.srt` рядом с роликом, JSON-отчёт о монтаже.

## Быстрый старт

Нужны **Python 3.10+**, **FFmpeg** в `PATH`, пакеты `numpy` и `Pillow`.

```powershell
cd cutcraft
python -m pip install -r requirements.txt
python -m cutcraft doctor
```

Простой прогон:

```powershell
python -m cutcraft auto video.mp4 --subs subs.srt --format 9:16 --style tiktok
```

Без установки пакета всё работает через `python -m cutcraft` из папки проекта.
Для команды `cutcraft` целиком:

```powershell
python -m pip install -e . --no-build-isolation
cutcraft --help
```

Или просто запусти `run.cmd` (CLI) и `gui.cmd` (окно).

## Сценарии

### 1. Нарезка с YouTube

```powershell
# 1080p, субтитры YouTube (русские, потом английские), вертикаль
python -m cutcraft "https://youtu.be/XXXXXXXXXXX" --format 9:16 --quality 1080

# Оставить главы видео как отдельные куски
python -m cutcraft "URL" --chapters

# Если YouTube просит войти: cookies из браузера, где ты залогинен
python -m cutcraft "URL" --cookies-from-browser chrome
```

Что происходит: `yt-dlp` скачивает видео и субтитры в `downloads/<id>/`,
CutCraft берёт `json3` с пословным таймингом, режет паузы и рендерит ролик.
Если субтитров нет, ролик соберётся без них.

Если cookies из браузера не читаются (занятая база Edge или DPAPI-шифрование
Chrome 127+), CutCraft **автоматически повторяет попытку без cookies**. То же
самое происходит, если YouTube отдал только SABR-поток без обычных форматов.
Для публичных видео на домашнем интернете этого обычно достаточно. Если YouTube
всё равно требует вход, нужен файл `cookies.txt` (см. «Решение проблем»).

> YouTube часто включает проверку «Sign in to confirm you’re not a bot» для
> серверных IP. На домашнем компьютере обычно достаточно
> `--cookies-from-browser chrome` (или `edge`, `firefox`). Ещё помогает
> обновить `yt-dlp`: `python -m pip install -U yt-dlp`.

### 2. Своё видео + готовые субтитры

```powershell
python -m cutcraft auto interview.mp4 --subs interview.srt `
  --style cinema --format 16:9 --max-clip 8
```

### 3. Только субтитры, без нарезки

```powershell
python -m cutcraft auto video.mp4 --no-cut --subs subs.srt --style neon
```

### 4. Текст сценария вместо SRT

Каждая непустая строка — одна реплика. Текст раскладывается по найденной речи
пропорционально длине строк.

```powershell
python -m cutcraft auto voiceover.mp4 --text script.txt --style karaoke
```

### 5. Ручной монтаж

```powershell
# Вырезать два куска
python -m cutcraft auto video.mp4 --cut 00:05-00:12 --cut 01:10-01:25

# Оставить только лучшее (автонарезка отключится)
python -m cutcraft auto video.mp4 --keep 00:10-00:40 --keep 02:00-02:30

# Посмотреть план, ничего не рендеря
python -m cutcraft plan video.mp4 --cut 00:05-00:12
```

### 6. Демо без интернета

```powershell
python -m cutcraft demo --out-dir demo
```

Сгенерирует синтетическое видео, музыку, SRT и соберёт два ролика:
вертикальный TikTok и кинематографичный 16:9. Это же — проверка, что всё работает.

## Стили субтитров

| Ключ | Для чего | Особенности |
|------|----------|-------------|
| `tiktok` | Reels, Shorts | Заглавные, жирный Segoe UI, караоке жёлтым, поп-анимация |
| `karaoke` | Клипы, каверы | Крупный текст, зелёная подсветка по словам |
| `neon` | Техно, игры | Голубое свечение в несколько слоёв + караоке |
| `cinema` | Влоги, интервью | Тёплый белый, мягкая тень, спокойное появление |
| `minimal` | Документальное | Белый текст на скруглённой полупрозрачной плашке |
| `impact` | Мемы, спорт | Плотный Impact, каждое слово всплывает отдельно |
| `podcast` | Говорящая голова | Сдержанный текст в тёмной плашке |

```powershell
python -m cutcraft presets
```

Полезные флаги:

```powershell
--font C:\fonts\Montserrat-ExtraBold.ttf   # свой шрифт
--font-scale 1.15                          # крупнее
--uppercase / --no-uppercase               # принудительно ВЕРХНИЙ регистр
--karaoke / --no-karaoke                   # подсветка по словам
--position bottom|center|top               # положение текста
--ass-out subs.ass --srt-out subs.srt      # куда сохранить субтитры
```

Сгенерировать только субтитры, без видео:

```powershell
python -m cutcraft subs --subs subs.srt --style tiktok --out subs.ass
python -m cutcraft subs video.mp4 --subs subs.srt --style cinema -o cinema.ass
```

## Как это работает

1. **Анализ.** Звук декодируется в mono 16 кГц. Считается RMS-огибающая (20 мс),
   порог речи подбирается по процентилям шума и речи. Паузы длиннее
   `--min-silence` становятся резами; вокруг речи остаётся `--pad`.
2. **План.** Куски склеиваются, короткие выбрасываются, длинные делятся по
   самому тихому окну (`--max-clip`), границы притягиваются к сменам сцен
   (`scdet`). Для каждого куска считается новый таймлайн.
3. **Субтитры.** Реплики чистятся, режутся по реальной ширине строки
   (Pillow + метрики шрифта), затем `map_span` переносит каждую реплику на новый
   таймлайн. Реплика, попавшая на склейку, делится на две.
4. **ASS.** Генерируется файл с караоке-тегами `\kf`, поп-анимацией `\t`,
   свечением через несколько слоёв `\bord`+`\blur`, скруглённой плашкой
   векторным рисунком `\p1`.
5. **Рендер.** Один фильтрграф ffmpeg: нормализация кадра, `trim`+`concat`,
   `ass`-фильтр, музыка с `sidechaincompress`, `loudnorm`, H.264/AAC.

## Команды

| Команда | Назначение |
|---------|------------|
| `auto` | Полный конвейер: нарезка → субтитры → рендер |
| `plan` | Показать сегменты, паузы и сцены без рендера |
| `subs` | Собрать `.ass`/`.srt` из SRT/VTT/ASS/текста |
| `info` | Метаданные файла или ссылки YouTube |
| `presets` | Список стилей и форматов |
| `doctor` | Проверка ffmpeg, шрифтов, numpy/Pillow, yt-dlp |
| `demo` | Сгенерировать демо и собрать пример |
| `gui` | Графический интерфейс |

`python -m cutcraft auto --help` — все флаги с пояснениями.

Основные:

```
--style tiktok            стиль субтитров
--format 9:16             кадр: source, 9:16, 16:9, 1:1, 4:5, 1080x1350
--fit crop|blur|pad       как вписывать исходник
--no-cut                  не вырезать паузы
--min-silence 0.45        порог паузы, сек
--pad 0.12                запас вокруг речи
--min-clip 0.6            выбросить реплики короче
--max-clip 0              ограничение длины куска для ритма
--scene-snap 0.35         привязка к сменам сцен
--subs FILE --text FILE   источник субтитров
--subs-lang ru,en         языки субтитров YouTube
--subs-offset 0.4         сдвиг субтитров, сек
--music FILE --music-volume 0.18
--punch 0.06              панч-ин на каждом втором куске
--crf 19 --encoder libx264
--dry-run                 план и субтитры без рендера
```

## Решение проблем

**`ffmpeg не найден`.** Добавь папку `bin` FFmpeg в `PATH` или задай
`FFMPEG_BIN=C:\ffmpeg\bin\ffmpeg.exe`.

**Кракозябры в консоли.** Запускай в Windows Terminal или `chcp 65001`.
CLI сам переключает вывод в UTF-8, но старый `cmd` может не переваривать
эмодзи и длинные тире.

**Субтитры пропали после нарезки.** Реплика целиком попала в вырезанную паузу.
Уменьши `--min-silence` или увеличь `--pad`, проверь `plan`.

**YouTube: «Sign in to confirm you’re not a bot».** Сначала попробуй вообще без
cookies — на домашнем интернете часто работает. Если нет — нужны cookies:
`--cookies-from-browser chrome` (браузер должен быть закрыт или залогинен),
либо `--cookies cookies.txt`.

**`Could not copy Chrome cookie database`.** Браузер держит файл cookies, и
`yt-dlp` не может его скопировать. Полностью закрой Edge/Chrome, включая фоновые
процессы (Диспетчер задач → Microsoft Edge → Снять задачу), и повтори. Если не
помогло — экспортируй `cookies.txt` (ниже).

**`Failed to decrypt with DPAPI`.** Новые Chrome/Edge (127+) шифруют cookies
так, что `yt-dlp` не может их расшифровать. Это не лечится закрытием браузера.
Рабочий путь — файл cookies:

1. Установи расширение **Get cookies.txt LOCALLY** (или **Cookie-Editor**).
2. Зайди на youtube.com под своим аккаунтом.
3. Экспортируй cookies для youtube.com в `youtube.com_cookies.txt`
   (JSON из Cookie-Editor тоже подойдёт — CutCraft сам переведёт его в Netscape).
4. В GUI укажи файл в поле **«…или cookies.txt»**, либо в CLI:
   `--cookies youtube.com_cookies.txt`.

Файл содержит доступ к аккаунту — не передавай его никому и удали после.

**`YouTube отдаёт видео только через SABR-стриминг`.** Это эксперимент самого
YouTube: в ответе нет обычных ссылок на форматы, только серверный ABR. `yt-dlp`
пока такие видео не качает (поддержку обещают). Что помогает:

1. Скачать **без cookies** — на домашнем IP SABR часто не включается.
2. Экспортировать cookies из **приватного окна** (новый сеанс), а не из
   обычного: SABR привязан к сессии аккаунта.
3. Попробовать другой аккаунт.
4. Обновить `yt-dlp` позже.

**Cookies «переданы, но не приняты».** Сессия устарела или сменился IP.
Экспортируй cookies заново из приватного окна и сразу запусти CutCraft, не
открывая YouTube в браузере после экспорта.

**Шрифт не применился.** Передай путь к `.ttf/.otf` в `--font`. CutCraft сам
копирует файл в папку рендера и берёт семейство из таблицы `name`.

**Медленный рендер.** Поставь `--encoder-preset veryfast`, `--fps 30`,
`--crf 23`. Для NVIDIA: `--encoder h264_nvenc`.

## Ограничения

- Локального распознавания речи нет: субтитры берутся из SRT/VTT/ASS/text или
  из YouTube. Это сознательно — не нужно качать модели на гигабайты.
- Один исходник за раз; пакетная обработка — в планах.
- Переходы между кусками — прямые склейки (jump cut), без `xfade`.
- Автонарезка рассчитана на речь; для музыки/эмбиента лучше `--no-cut`.
- Часть видео YouTube отдаёт только через SABR-стриминг — их `yt-dlp` пока
  не скачивает. CutCraft показывает понятную ошибку и подсказки.

## Структура

```
cutcraft/
  cutcraft/
    analyze.py     огибающая, паузы, сцены
    plan.py        сегменты и новый таймлайн
    subtitles.py   SRT/VTT/ASS/json3, нарезка, retime
    assgen.py      ASS: караоке, анимация, свечение, плашки
    render.py      фильтрграф ffmpeg и рендер
    pipeline.py    сквозной конвейер
    youtube.py     yt-dlp, субтитры и главы
    cookies.py     JSON → Netscape, безопасная работа с cookies
    cli.py         команды и прогресс
    gui.py         Tkinter-интерфейс
    demo.py        генератор демо
  tests/           24 unit-теста
  demo/            исходники, ролики и постер
```
